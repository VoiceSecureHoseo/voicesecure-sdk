# VoiceSecure SDK

음성을 딥보이스(음성 복제 AI)로부터 보호하는 임베디드 SDK.

## 빠른 시작 (개발자)

```bash
git clone git@github.com:VoiceSecure/voicesecure-sdk.git
cd voicesecure-sdk

python -m venv .venv
source .venv/Scripts/activate

pip install -e ".[dev]"
pre-commit install
```
